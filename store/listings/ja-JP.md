## Title
Pathrova – パスが長すぎる問題のチェックツール

## Short description
移行前に、OneDrive と SharePoint が受け付けない長すぎるパスや使えないファイル名を、1回のスキャンでまとめて検出。エラーを1件ずつ潰す必要はありません。プレビューと元に戻す機能つきで安全に名前を変更し、CSV または PDF でレポート出力。オフライン動作、アカウント不要。7日間無料でお試しいただけます。

## Description
同期クライアントが「パスが長すぎます」「ファイル名が無効です」と知らせるのは同期の最中だけで、しかも1件ずつ。数万フォルダーのファイルサーバーでは、解消に何日もかかることがあります。
Pathrova は同期の前にフォルダーツリー全体を一度でスキャンし、問題をすべてまとめて表示。安全に直せるものは、プレビューと元に戻す機能つきで修正できます。7日間無料でお試しください。

Pathrova がチェックする項目
• クラウドのパス長：ライブラリのパスを含めて400文字。URLエンコード（スペース = %20）で厳密に数えるオプションあり
• ローカル同期パス：同期フォルダーを含めて520文字（例：「C:\Users\Max\OneDrive - Contoso」）
• Office の上限：パスが256文字を超えるファイルは Word、Excel、PowerPoint で開けません
• 255文字を超える名前
• 使用できない文字： " * : < > ? / \ | および制御文字
• 予約名：CON、PRN、AUX、NUL、COM0～9、LPT0～9、.lock、~$…、_vti_、最上位階層の「forms」
• 先頭または末尾のスペース、末尾のピリオド
• # と %（組織によってはブロックされます）、; と &（Office）
• ご自身で設定したリストに基づくブロック対象のファイルの種類、250 GB を超えるファイル
• シンボリックリンクとジャンクション、同期されないシステムファイル、アクセス権のないフォルダー
• 1回の同期で30万件を超えるアイテム

フォルダーのパスが長すぎる場合は、そのフォルダーを影響するアイテム数とともに1回だけ表示します。一覧が膨れ上がらず、見やすいままです。

安全に名前を変更
• 修正可能なすべての問題に対して提案を表示：文字の置き換え、スペースとピリオドの削除、予約名への補足、長いファイル名を単語の区切りで短縮（拡張子は維持）
• 同じフォルダー内の名前の重複は自動で解消（例：「名前 (2).docx」）
• 選択式のプレビュー。確認するまで何も変更されません
• 名前の変更はすべてログに記録され、ワンクリックで元に戻せます

お客様や同僚に渡せるレポート
• CSV 出力（Excel にそのまま使え、修正案つき）と、問題の種類ごとの集計つき PDF レポート

大規模なファイル共有にも対応
• 10万ファイル超でも1回のスキャンで完了。いつでも中止できます
• ローカルドライブ、USB ディスク、ネットワーク共有（\\server\share）
• エラー・警告・問題の種類で絞り込み、検索にも対応

プライバシー
Pathrova はすべてお使いの PC 上で動作します。アカウント不要、クラウド接続なし、テレメトリなし、広告なし。読み取るのは選択したフォルダーだけです。

アプリの画面はドイツ語と英語で利用でき、ライトテーマとダークテーマに対応しています。

ご注意：Pathrova はチェックとレポートを行うツールです。同期や移行の成功を保証するものではなく、お使いの組織の設定によって結果が異なる場合があります。ルールは Microsoft が公開している情報（2026年11月時点）に基づいています。Microsoft、OneDrive、SharePoint は Microsoft グループ企業の商標です。Pathrova は独立した製品です。

## Features
1. フォルダーツリー全体を1回でスキャンし、OneDrive と SharePoint の問題をまとめて表示
2. パス長のチェック：400文字（クラウド）、520文字（同期）、256文字（Office）。URLエンコードで数えることも可能
3. プレビューつきの安全な名前変更の提案。確認するまで何も変更されません
4. 元に戻すログ：名前の変更はワンクリックで取り消せます
5. お客様・同僚・ドキュメント用の CSV / PDF レポート
6. 10万ファイル超でも高速。中止も可能で、USB ディスクやネットワーク共有にも対応
7. 使えない文字、予約名、先頭・末尾のスペース、末尾のピリオドを検出
8. 問題の種類（エラー、警告、注意）ごとにグループ化。フィルターと検索つき
9. ブロック対象のファイルの種類を自分で設定。250 GB 超のファイルや30万件超のアイテムも通知
10. オフライン、アカウント不要、テレメトリなし。7日間無料。ドイツ語・英語対応、ライト／ダークテーマ
